LEVÁNTATE 5.0 - GUÍA DE ACTUALIZACIÓN
=====================================

TU SITIO YA EXISTE: github.com/CIzanami-crypto/levantate
No hace falta crear otro repositorio, borrar la aplicación ni instalar un APK.

1) Antes de actualizar, abre Levántate 4.0 y entra a Ajustes > Respaldar.
   Guarda el JSON en lugar seguro. NUNCA lo subas al repositorio.
2) En GitHub abre tu repositorio "levantate".
3) Pulsa Add file > Upload files. Arrastra TODOS los archivos de este ZIP
   sin meterlos en otra carpeta (index.html, sw.js, manifest, iconos...).
4) Si GitHub te propone reemplazar archivos con el mismo nombre, confirma.
5) Haz clic en Commit changes. GitHub Pages publicará la versión nueva.
6) Abre la aplicación instalada en Android > Ajustes > Buscar actualizaciones.
   Si aparece "Hay un nuevo capítulo", pulsa Actualizar ahora.
   Si no, cierra y vuelve a abrir la PWA con internet tras publicarse.

NOTIFICACIONES
- Ajustes > Voces que llegan a ti > Activar avisos > Permitir.
- Elige 3 horas de ánimo (por defecto 09:00, 14:00, 19:00), hitos de ayuno,
  diario (21:00) y alertas de nuevas versiones.
- Para recibir avisos programados con esta versión, debes mantener la PWA
  abierta en primer plano (o volver a ella cerca del horario configurado).
  El navegador NO puede garantizar notificaciones a horas fijas al cerrar
  completamente la aplicación usando únicamente GitHub Pages.
- Para avisos en segundo plano incluso con la app cerrada hace falta habilitar
  Web Push en un servicio externo (servidor + suscripciones + programación).
  sw.js ya contiene el receptor para ese trabajo futuro, pero aún no hay
  suscripción push ni servidor emisor configurados.
- No se envían tres avisos atrasados de golpe. Se evita saturarte.
- Las notificaciones son opcionales. No son una alarma sanitaria ni una
  indicación de cuánto tiempo debes seguir ayunando.

DATOS Y PRIVACIDAD
- Las notas y el historial siguen guardados en localStorage (clave
  levantate_ayuno_v1), compatible con Levántate 4.0 en el MISMO dominio.
- Si antes usabas un HTML local, debes respaldar allí y restaurar en la PWA.
- No se suben diarios, ayunos, contraseñas ni datos a GitHub Pages.
- Borrar datos del sitio, cambiar de navegador o reinstalar puede eliminarlos.
  Haz respaldos ocasionales.

CAMBIOS
- 216 frases nuevas: ahora 486 originales entre nueve voces.
- Sorteo aleatorio sin repetir frases hasta recorrer la colección escogida.
- Preferencias configurables de notificaciones y prueba de permiso.
- Avisos de actualizaciones y recepción Web Push preparados para futuro backend.
- Se mantienen diario, juramento, contador, metas e historial.
